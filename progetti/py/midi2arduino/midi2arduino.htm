Cos'è/Come funziona?
Ti è mai capitato un buzzer e un arduino fra le mani? Hai mai voluto riprodurre la tua canzone preferita?
Se si, questo può essere il progetto per te! Con un po di passaggi ci riuscirai.
Questo consiste nel prendere un file MIDI (un file audio della tua canzone, vedi spiegazione sotto)
e trasformarlo in un array di note compatibili con il codice di Arduino.

DOMANDE/RISPOSTE

Cos'è un file MIDI??
Un file MIDI è effettivamente un file audio, ma effettivamente contiene le istruzioni per far suonare una certa canzone.
Ad esempio, se tu ascolti una canzone su un CD sentirai la voce del cantante, gli strumenti musicali, riverbero etc..
Se ascolti la stessa canzone su file MIDI sentirai SOLAMENTE gli strumenti musicali.
La musica la sta generando il tuo computer in quel momento, infatti cambia da computer/computer o telefono/telefono..
Il tuo computer diventa l'orchestra che suona mediante un sintetizzatore!

Istruzioni - PREPARARE MIDI (PT.1):

1. Cerca su Google il file MIDI... puoi provare a cercare "(titolocanzone) midi download"
SITI DOWNLOAD MIDI CONSIGLIATI (suddivisi x artista)
2. Ottenuto il file controlla che si senta correttamente la melodia giusta.
3. Collegati al sito e carica il tuo file MIDI.
4. Ad esclusione, rimuovi le tracce (gli strumenti) che non ti interessano,
lascia solo UNA MELODIA PRINCIPALE, altrimenti non funzionerà!!!
Puoi cercandole mutandole per sentire quella giusta, poi tasto DX -> Delete Track.
5. Esporta il file MIDI a UNA TRACCIA su File -> Download MIDI File
ATTENZIONE!! Segnati i numeri di battuta da dove vuoi che parta e dove vuoi che finisca.
6. Collegati al sito e inserisci le battute di inizio e di fine, quindi scarica il file.

Istruzioni - CONVERTIRE MIDI (PT.2):
7. Assicurati di avere Python, (se non l'hai già installato, )
8. Apri il CMD, digita "python (ilnomedelfiledellozip).py (nomedeltuomidiscaricato).midi"
9. Invia, ti genererà un file .h! quelle sono le tue note musicali convertite per arduino.!
